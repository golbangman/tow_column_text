# 재생 위치에 맞춘 자막 자동 스크롤

**Symptom**: 지금은 사용자가 영상을 보며 번역 영역을 마우스 휠로 직접 스크롤해
재생 위치를 따라간다. 재생 위치에 맞춰 현재 문장을 강조하고 자동으로 스크롤해 주면
편하다.

**Observed evidence**: shape-idea 세션(youtube-url-translation). 사용자가 요청했다가
"맨처음 의도대로 진행하고 향후 자동 스크롤 지원하자"로 정리함. 현재 스펙은 수동
스크롤만 다룬다.

**Suspected cause**: 자막 추출이 세그먼트를 이어붙인 뒤 `.!?`로 다시 문장을 쪼개므로
문장과 세그먼트가 1:1이 아니고, 문장별 타임스탬프가 없다. 단순 iframe 임베드는
재생 위치를 읽을 수 없다.

**What was tried**: 이번 스펙에서는 범위 밖으로 두고 타임스탬프를 버림
(`docs/decisions/caption-extraction.md`).

**Proposed next step**: (1) 자막 추출 시 각 세그먼트의 시작 시각을 함께 보관한다.
(2) 문장을 쪼갤 때 각 문장에 그 문장이 시작된 세그먼트의 시각을 근사로 붙인다.
(3) YouTube IFrame Player API로 `getCurrentTime()`을 주기적으로 읽어, 시각이 지난
마지막 문장을 강조하고 그 문장이 보이도록 번역 영역을 스크롤한다. (4) 사용자가 휠을
돌리면 자동 따라가기를 잠시 멈추고 "다시 따라가기"로 재개한다.
